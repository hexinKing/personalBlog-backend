# PRD to Figma AI Prompts

> 将产品需求转化为 Figma Make 可用的设计提示词，让不懂设计的产品经理也能高效地用 Figma AI 生成符合预期的页面设计。

## 这个 Skill 解决什么问题

产品经理写完 PRD 后，不知道怎么跟 Figma AI 沟通来生成页面设计。常见的痛点：

- 直接把需求丢给 Figma AI，生成的结果和预期差距很大
- 不知道怎么描述页面布局、组件、交互
- 多个页面之间风格不一致
- 反复修改浪费大量 AI credits

这个 Skill 帮你把需求自动转化为**结构化的 Figma Make 提示词**，一次生成就能拿到满意的结果。

## 支持的输入方式

| 输入方式 | 示例 | 适用场景 |
|---------|------|---------|
| **PRD 文档** | Markdown / Word / PDF | 有完整的产品需求文档 |
| **竞品截图** | .png / .jpg 图片 | 想参考竞品的设计 |
| **竞品网站** | URL 地址 | 想参考竞品的整体风格 |
| **一句话描述** | "帮我做一个 CRM 客户列表页" | 快速出图，边做边想 |

## 使用场景

### 场景 1：有 PRD，想快速出设计稿

```
你：根据这个 PRD 文档生成 Figma 提示词
    [上传 prd.md]

Skill：
  1. 解析 PRD，提取页面列表和功能需求
  2. 按用户流程顺序生成每个页面的提示词
  3. 如果 PRD 有明确的设计规范（色号、字体等），自动生成 guidelines.md
  4. 输出 .md 文件，可直接复制到 Figma Make
```

### 场景 2：参考竞品，快速复刻

```
你：参考这个网站 https://example.com 输出一份 Figma 提示词

Skill：
  1. 抓取网页内容，分析布局结构和视觉风格
  2. 追问你的业务上下文（产品是什么、目标用户、差异化）
  3. 把竞品的布局和组件融入提示词
  4. 输出 .md 文件
```

### 场景 3：一句话出图

```
你：帮我生成一个 CRM 客户列表页的 Figma 提示词

Skill：
  1. 追问关键信息（目标用户、核心功能、平台）
  2. 基于常见页面模板生成提示词
  3. 输出 .md 文件
```

### 场景 4：参考竞品截图

```
你：参考这个截图，帮我生成 Figma 提示词
    [上传 screenshot.png]

Skill：
  1. 分析截图的页面结构、组件和视觉风格
  2. 追问业务上下文
  3. 生成融入竞品设计的提示词
  4. 输出 .md 文件
```

## 输出格式

Skill 会生成一个 `.md` 文件，包含：

```markdown
# Figma AI 提示词 - [项目名称]

## 📋 Figma Make Guidelines（如果有明确的设计规范）
  → 复制到 Figma Make 的 guidelines.md 文件中

## 📱 页面 1: [页面名称]
  🎯 主提示词     → 复制粘贴到 Figma Make 对话框
  🔧 调整提示词   → 生成后微调用
  💡 使用建议     → 检查要点和迭代策略

## 📱 页面 2: [页面名称]
  ...

## 📌 使用指引
  → 推荐生成顺序、页面流程关系、一致性检查清单
```

## 核心设计理念

### 1. 前置密集

第一个 prompt 包含尽可能多的信息，减少后续修正轮次。每次修正都消耗 AI credits，好的提示词可以一次命中。

### 2. 按屏拆分

每个页面一个独立 prompt，不要把整个产品的所有页面塞进一个 prompt。Figma AI 对单个页面的理解能力远好于多个页面。

### 3. 页面串联

每个页面的提示词开头都会说明"这个页面在整体流程中的位置"，比如"这是用户从项目列表页点击某个项目后进入的页面"。这样 Figma AI 能更好地理解上下文。

### 4. guidelines.md 条件触发

只有当输入中包含明确的设计规范（色号、字体、圆角等具体数值）时，才会生成 guidelines.md。没有明确规范就不生成，避免自作主张。
